# Aplikasi Ujian Terminal
Aplikasi Ujian Terminal adalah program berbasis C++ yang memungkinkan penyelenggaraan ujian melalui antarmuka terminal. Aplikasi ini mendukung dua jenis pengguna: Guru dan Siswa.

Fitur Utama:
Untuk Guru
- Pembuatan Soal: Guru dapat membuat dan menyimpan soal ujian.
- Penyimpanan Soal dan Kunci Jawaban: Soal ujian beserta kunci jawabannya disimpan dalam file.
- Enkripsi Kunci Jawaban: Kunci jawaban yang dibuat oleh guru dienkripsi menggunakan Caesar Cipher dan Playfair Cipher untuk menjaga kerahasiaan.
Untuk Siswa
- Pengerjaan Soal: Siswa dapat mengerjakan soal ujian yang telah dibuat oleh guru.
- Penilaian Otomatis: Jawaban siswa dinilai secara otomatis berdasarkan kunci jawaban yang terenkripsi.
- Enkripsi Jawaban: Jawaban siswa juga dienkripsi menggunakan Caesar Cipher dan Playfair Cipher sebelum disimpan.

Teknologi yang Digunakan
- Bahasa Pemrograman: C++
- Enkripsi: Implementasi Caesar Cipher dan Playfair Cipher untuk mengenkripsi data.
